Model API
Call any Coarena model from your own code. Free: $5 a day, and Coarena pays.
Quick start
1Get a key Create one on your API page. Free, no card.
2Set the base URL https://coarena.ai/api/v1 for OpenAI SDKs, https://coarena.ai/api for Anthropic's.
3Call Any model id from the list, as the model.
Call a modelCopyCopiedSelect itcurl https://coarena.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $COARENA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-fable-5",
       "messages": [{"role": "user", "content": "Hello"}]}'
Copy for your agentCopiedSelect itGet a key
Base URLs

EnvironmentCopyCopiedSelect it# OpenAI SDKs, Codex, LangChain

# Anthropic SDK, Claude Code
export ANTHROPIC_BASE_URL=https://coarena.ai/api
export ANTHROPIC_AUTH_TOKEN=$COARENA_API_KEY

Feedback
Rate any reply up or down by the id it came with, and say why: tags (correct, helpful, fast, wrong, unhelpful, refused, too_slow, bad_format, unsafe, concise, thorough, creative, good_code, followed_instructions, made_up, incomplete, too_long, off_topic, bad_code, ignored_instructions) and a note of up to 2,000 characters. null takes the rating away.
Rate a replyCopyCopiedSelect itcurl https://coarena.ai/api/v1/feedback \
  -H "Authorization: Bearer $COARENA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"request_id":"<reply id>","rating":"up"}'
# Python (openai), after reply = client.chat.completions.create(…)
client.post("/feedback",
            body={"request_id": reply.id, "rating": "up"}, cast_to=object)
Limits
Free: $5 of model use a day, and Coarena pays. 30 requests a minute, 2 at once. An account may also have a daily request limit, set by Coarena.
Today's use and your limitsCopyCopiedSelect itcurl https://coarena.ai/api/v1/limits \
  -H "Authorization: Bearer $COARENA_API_KEY"
Asking for more
One call, after your first one. With no field it asks for the next step up, $10 a day; name requests_per_minute (up to 600), or requests_per_day if your account has a daily request limit, to ask for those.
Ask for higher limitsCopyCopiedSelect itcurl https://coarena.ai/api/v1/limits/requests \
  -H "Authorization: Bearer $COARENA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"usd_per_day":10}'
# More a minute: -d '{"requests_per_minute":60}'
# Where it stands: GET /api/v1/limits
# Withdraw it: DELETE /api/v1/limits/requests/current
Errors
OpenAI routes answer in OpenAI's error shape, /v1/messages in Anthropic's. A limit 429 says exactly how to ask for more.
The daily-limit 429CopyCopiedSelect it{
  "error": {
    "type": "insufficient_quota",
    "code": "insufficient_quota",
    "message": "Daily free limit reached: $5.00 of model usage today. …",
    "limit_increase": {
      "ask": {
        "method": "POST",
        "url": "https://coarena.ai/api/v1/limits/requests",
        "body": {
          "usd_per_day": 10
        }
      }
    }
  }
}
